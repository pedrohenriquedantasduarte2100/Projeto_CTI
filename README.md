# Projeto CTI

Este repositório contém as entregas das atividades de Checkpoint (CP).

## 📂 Organização do Repositório

As entregas da **CP1, CP2, CP3 e CP4** estão organizadas pelo próprio nome do arquivo. 

Para encontrar uma entrega específica, basta procurar pelo prefixo correspondente no início do nome do arquivo. Por exemplo:
* `Entrega_CP1.html`
* `Entrega_CP2.jpeg`

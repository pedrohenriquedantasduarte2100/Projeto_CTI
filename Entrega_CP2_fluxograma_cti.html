WebFilter — Fluxo de decisão

Decisão
A solicitação envolve bloqueio/liberação por regras de horário ou categorias?
✓ SIM
Filtros Avançados: informar qual categoria e tipo de usuário. Para horários, usar função "schedule" com início e fim.
✗ NÃO
Erro no WhatsApp: verificar logs do firewall. Se há registros mas não funciona, problema é no dispositivo ou operadora.

DHCP/DNS — Fluxo de decisão

Decisão
A solicitação é sobre alteração ou novo apontamento de DNS?
✓ SIM — DNS
Apontamentos feitos exclusivamente pela equipe. Coletar: {DOMÍNIO}, Tipo (A/CNAME/MX/TXT), Valor e TTL (padrão 3600s).
✗ NÃO — DHCP/IP
Ranges configurados no firewall são {RANGES}. Para reserva de IP fixo, coletar o endereço MAC do equipamento.

SD-WAN / Links — Fluxo de decisão

Decisão
O cliente reclama de oscilação ou link fora do ar?
✓ SIM
Comportamento padrão: link com menor latência assume automaticamente. Acionar {OPERADORA} se houver perdas ou latência alta.
✗ NÃO — Alterar link
Ajustar métrica de prioridade nas regras de SD-WAN. Confirmar qual link deve ser o preferencial.
Decisão
O equipamento responde ao teste de Ping?
✓ SIM
Delay de sincronização. Equipamento operacional. O painel do cliente atualizará em alguns minutos.
✗ NÃO
Erro PPPoE ou Link Caído. Autenticação depende da operadora. Cliente deve acionar {OPERADORA} com protocolo de atendimento.

Interfaces / Equipamento — Fluxo

Decisão
O usuário está na rede local da empresa?
✓ SIM — Rede local
Verificar conectividade interna. Checar estado das interfaces no firewall e latência interna.
✗ NÃO — Rede externa
Erro de conexão esperado. Orientar a testar em rede externa (4G) antes de escalar.
Equipamento offline: verificar se responde a ping. Se sim, aguardar sincronização do painel (alguns minutos).

VPN — Fluxo de decisão

Decisão
O usuário está na rede local da empresa?
✓ SIM — Verificar AD
Verificar se usuário está no grupo correto do AD / SSL VPN.
✗ NÃO — Teste 4G
Erro esperado fora da rede. Testar em 4G e enviar Modelo de Resposta VPN (Pág. 14).

NAT / Acesso Externo — Fluxo

Coleta obrigatória
Solicitar: IP interno, portas a abrir, protocolo (TCP/UDP) e IP de origem
Decisão
O direcionamento de NAT está correto mas continua sem acesso?
✓ SIM — Firewall interno
Causa mais comum! Verificar se o dispositivo (DVR/Servidor) possui firewall próprio bloqueando as portas.
✗ NÃO — Mitigação
Aplicar políticas de origens autorizadas. Agendar atualização de firmware em janela de manutenção.

Webmail / E-mail — Ações

Caixa cheia: mover mensagens para "Arquivo Morto" no Webmail ou limpar Lixeira/Spam.
Conta é Apelido (Alias): login deve ser feito com dados da conta original.
Portas Outlook: IMAP 993 (SSL) · SMTP 587 (TLS)

Autenticação / Acesso — Fluxo

Decisão
A solicitação é para WiFi persistente (Captive Portal) ou máquina "comprometida"?
✓ WiFi persistente
Modo Persistent: configurar para o dispositivo não precisar reautenticar. Coletar endereço MAC do equipamento.
✗ Credenciais
Troca de Senhas (Firewall/VPN/WiFi) só realizada mediante chamado autorizado pelo responsável técnico.
Limpeza de Cache: na maioria dos casos é registro temporário. O status normaliza sozinho após alguns minutos.

Logs / Monitoramento — Fluxo

Decisão
O cliente quer analisar histórico passado ou ver o tráfego agora?
✓ Histórico — Relatório
Confirmar período ({DATA_INICIO} a {DATA_FIM}), Usuário/IP e tipo: Navegação, Banda, VPN ou Eventos.
✗ Tempo real
FortiGate em Dashboard > FortiView para visualizar tráfego por aplicação e usuário no momento atual.

Gerência / MyPortal / CVE — Fluxo

Decisão
O chamado é sobre uma vulnerabilidade (CVE) publicada?
✓ SIM — CVE
Guia Rápido MyPortal (myportal.cti.com.br): Novo Chamado, Meus Chamados e Acesso Remoto.
✗ NÃO — Firmware
Agendar atualização de firmware em janela de manutenção. Aplicar políticas de mitigação de risco.

Backup — Ações

Solicitar para restauração: {ITEM} (arquivo/pasta/VM), {DATA} do backup e se o destino é o local original ou novo caminho.
Infraestrutura: backups rodam conforme agendamento. Datacenters em SP (Barueri e Santana de Parnaíba). Recomendação: Veeam Backup & Replication.

Antivírus / Segurança — Fluxo

Decisão
O dispositivo apresenta comportamento anormal (lentidão extrema, pop-ups)?
✓ SIM — Contenção
1. Isolar o dispositivo da rede. 2. Executar varredura completa offline. 3. Acionar equipe para análise dos logs de tráfego.
✗ NÃO — Alerta falso
Avisos costumam ser registros em cache que normalizam sozinhos em minutos. Monitorar.
